# Case 05

Request:

`Audit this team, I only have the species: Whimsicott, Charizard, Rillaboom, Incineroar, Urshifu-Rapid-Strike, Raging Bolt. No items, moves, or spreads yet.`

Checks:

- states the assumed format and that items, moves, and spreads were not supplied
- labels each finding that depends on an assumed set and says which detail would confirm or change it
- still identifies species-level structural issues such as speed control, Fake Out access, or shared weaknesses
- recommends which missing details to lock first, ordered by how much they change the audit
- keeps residual risk honest about what cannot be judged without sets

Failure triggers:

- invents specific items, moves, or EV spreads and audits them as if the user supplied them
- gives only generic type-chart commentary because sets are missing
